# TIMED

**Temporizador Integrado Multiconjunto dos Esporas Douradas**

Cronometragem de cross country (hipismo completo) para o júri: vários conjuntos em pista ao mesmo tempo, paradas neutralizadas, Tempo Concedido, Tempo Limite e penalidades conforme o Regulamento CBH. Funciona offline e pode ser instalado na tela de início do celular.

Acesse: https://mauriciopav1809-debug.github.io/timed/

Desenvolvido pelo 1º Ten Veiga, Espora Dourada nº 1370.
